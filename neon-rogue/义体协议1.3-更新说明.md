# 霓虹深潜 · 义体协议 1.3

## 这次重做的核心

不是让所有攻击都变成“等红圈、走一步”。不同敌人建立不同的战斗秩序，考验爆发、承伤、清群、持续输出、护盾回复、吸血或资源管理。强力义体可以压制甚至跳过部分机制，不根据玩家配装动态抵消优势。

- 恢复原 Boss 基础血量与攻击公式；技能全部直接排列，取消横向滚动。
- 撤销“打 Boss 破绽免费回能”。突击者仍需管理弹药、换弹底材和能量。
- 保留此前的仓库按实例消费、训练隔离、换装不白送治疗等修复。

## 九种不同的战斗方式

| Boss | 独立机制 |
|---|---|
| 裂齿猎犬 | 咬穿护盾才留伤，随后加速追猎；快突进、深蓄咬合、低血连咬。伤口不额外制造无条件持续伤害。 |
| 蜂巢母体 | 卵孵化强化个体，巢穴持续生产，酸蚀占地；生产源是可被直接摧毁的实体。 |
| 锈甲守望 | 正面装甲与机体热量两套状态：打穿装甲或迫使过热开阀；侧后攻击、液压动作与爆发各有作用。 |
| 棱镜枪骑 | 先侧移再射击，磁钩拉人后自己弹射，轨道炮留下固定压制线。 |
| 磁雷蛛 | 真实雷点之间形成感应带，踏线点燃两端引信，连锁与遥爆改变活动空间。 |
| 镜渊 | 可破坏镜面改变反射方向并增加发射源；镜阵积累越久，光路越密，Boss 会与镜面换位。 |
| 终焉之眼 | 旋转激光、过曝与神经灼照；护盾、回复、吸血和输出速度承担不同作用，同时侵蚀游戏内 HUD。 |
| 万巢之母 | 中继、再生、递归扩军与护卫生产组成网络；拆中继暂断生产和再生，不让已生成部队一起停机。 |
| 三相之骸 | 实体重刃→真实玩家足迹延迟重放→自身冲锋轨迹回卷；切相清旧回声，闪现不补成普通走路路径。 |

普通敌人也保留各自职责：即时连发炮台、快慢撞击、近身自爆、递归召唤、重装锤击、治疗保护与尸体重构、高阶突入追击。召唤者的子代仍可继续召唤。

## 义体的强度要真正生效

芯片主副词条进入实际属性计算；枪械、义体主动、幽灵技能、机甲与友方单位接入统一的暴击、处决增伤和吸血路径。修正近战溅射继承错误护甲、闪现距离累计、主动冷却缩减、辅助主动成长等问题。特殊吸血效果避免重复结算。

## 赛博演出

- 蓄力斩击、贯穿射线、错峰连射、导弹曲轨、护盾分片、闪现残影、时缓扫描分型表现。
- Boss 登场机体扫描、阶段超频、原创台词；大招有短促扫描冲击与色分离。
- 终焉之眼的 HUD 边框与技能条纹侵蚀、镜渊的错误回声均有来源；击杀、清场和换局解除。
- 台词使用游戏内敌方通知条，不调用手机系统通知。覆盖层不拦截点击，不禁用按钮，不改写技能名字或血量。
- 危险区域用红光和蓄能状态表达，没有数字倒计时棋盘。支持系统“减少动态效果”。

## 正式训练场

保留自由训练：八个部位直接选全部 **100 件义体**、6种芯片×6种品质、10种道具、39种普通怪和9个Boss；可调等级、属性及模拟深度，可手动补充职业资源、重置冷却。

正式包**不含开发压力场景、开发强力配装预设或 `window.__neon` 调试接口**。训练从空场开始；击杀不自动往配装塞奖励或弹出升级，不写主线统计、仓库、图鉴、成就或核心。

## 验证与边界

- 156项浏览器回归通过：包括全部100件安装选择、其中60件主动施放、芯片36种组合、完整敌人库、原Boss初始血攻、独立机制、时停、旧仓库实例、训练隔离、演出纯渲染与解除、正式UI。

- 递归单位及场地保留设备安全预算；到达预算延后新增，不偷偷删除已有敌人。
